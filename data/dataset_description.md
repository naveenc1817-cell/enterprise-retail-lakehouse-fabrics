# Dataset Description

## Dataset

Brazilian E-Commerce public dataset.

## Purpose

The dataset represents a retail e-commerce business with customers, orders, products, sellers, payments, and logistics data.

## Files Used

| File | Purpose |
|---|---|
| olist_customers_dataset.csv | Customer data |
| olist_orders_dataset.csv | Order data |
| olist_order_items_dataset.csv | Order line items |
| olist_order_payments_dataset.csv | Payment data |
| olist_products_dataset.csv | Product data |
| olist_sellers_dataset.csv | Seller data |
| olist_geolocation_dataset.csv | Geolocation data |
| product_category_name_translation.csv | Product category translation lookup |
| customer_updates.csv | Incremental customer updates |
| order_updates.csv | Incremental order updates |

## Notes

Raw data files are not included in this repository. This repository focuses on pipeline design, transformation logic, notebooks, screenshots, and documentation.
